Prepared for owner approval. No publication or deployment has occurred in this preparation step.

## Included

- Clearly labeled Educational Explorer, with an original analytic illustrative trajectory and procedural graphics; starts in 2D without WebGL allocation.
- Optional interactive 3D, four cameras, playback, timeline, velocity direction, context recovery and scene lifecycle controls.
- Authentic local-data import support: explicit consent, two-file validation, and distinct historical byte-match versus compatible unauthenticated labels. Files remain local in browser memory; no upload, analytics or persistence.
- Verified nominal encounter reconstruction engine, with scientific algorithms and original tests preserved. Authentic execution requires separately held or legitimately acquired compatible input data.
- Source ZIP with locked setup/build instructions and tests; prebuilt local application ZIP with Windows launcher and required third-party notices.

## Excluded and scientific scope

No private historical JPL datasets, original API responses, normalized state vectors, generated authentic encounter payloads, private engineering reports or prior private Git history are bundled. No official-data redistribution authorization is asserted. Local import is not permission to redistribute records. This software reconstructs a nominal Earth encounter using NASA/JPL information; it does not independently determine asteroid orbits or predict impacts. Horizons and CAD share model lineage. An integrity byte match is not a JPL digital signature. NASA/JPL do not endorse this project.

The existing v0.1.0-source release is preserved. The complete authentic-data application is not hosted by this release. Separate data-bearing R0 remains PARTIAL. Apache-2.0 applies to original owned code only; dependencies and any independently supplied data retain separate terms.

## Memory limitation — original target UNMET

The approximately 400 MiB absolute total-browser working-set target remains UNMET. A matched blank Chrome median alone was 496.60 MiB. A 604.157-second, 294-sample Windows Chrome 156 headless campaign at 1280×1000 using Intel UHD D3D11 measured educational 2D median 562.13 MiB, educational 3D playback median 609.84 MiB, authentic-local 2D median 597.80 MiB and authentic-local 3D playback median 620.02 MiB. Overall observed peak was 771.35 MiB. Relative to blank, these median increments were 65.53, 113.24, 101.21 and 123.42 MiB respectively; they include browser/driver/tooling overhead and are not exact ownership accounting.

Final blank after page cleanup retained 88.98 MiB working set, 42.08 MiB private commit and 16.05 MiB USS versus the initial median. This finite test does not prove absence of leaks. Working-set sums can double-count shared pages; private commit is not resident RAM; VRAM was not measured. No guarantee of the legacy target or universal performance is included. A future incremental-memory acceptance proposal requires separate owner approval; none replaces the original criterion here. Source-only publication approval must expressly acknowledge this disclosed unmet requirement and does not make B2-M GO.

## Install, launch and reproduce

For the prebuilt ZIP, fully extract APOPHIS_OBSERVATORY, install/use Python 3.9+ and a modern browser, then double-click START_OBSERVATORY.cmd. It serves its own folder on loopback only; see README_WINDOWS.md for manual launch and port conflicts. No Docker, package installation, external API or dataset is needed for education. Do not open index.html with file://.

For source setup and tests, follow README.md (Python 3.12, Node 24, pnpm 11.25.0, frozen lockfiles). Authentic reconstruction needs external supported files and their provenance; no synthetic fixture substitutes for authentic validation. The browser never retrieves JPL data. Acquisition is a separate user-operated workflow subject to current API policy and contact requirements. No imported input is automatically official. Clear/reload returns to education.
